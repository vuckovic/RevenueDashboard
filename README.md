# Revenue Dashboard v2

Collects paid-invoice data from the Workday report **DV_Customer Invoices** (via API, ISU `ISU_AR_Collector_DV`, security group `ISG_AR_Collector`) into an Excel Online sheet used as a Power BI data source.

## Credentials
Credentials are **never** stored in this repo. Copy `.env.example` to `.env` and fill in values locally.
